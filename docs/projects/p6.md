# Project 6: Industrial Defect Inspection with a Retraining Loop (InspectAI)

> **Customer Engagement**: Halden Industrie GmbH (Manufacturing Operations, Plant Hamburg `DE-HAM`)  
> **Status**: In Progress — Milestones 1 & 2 Delivered  
> **Guiding Principle**: Unsupervised anomaly detection on normal "good" parts only to catch unseen defect types; supervised defect classification for known failure modes; cost-based decision operating point; automated closed-loop retraining and shadow promotion. Local CPU latency $< 100$ ms per part.

---

## 1. Customer Story & Problem Statement

**Mehmet Yilmaz (Quality Lead)** at Halden Industrie (Hamburg plant `DE-HAM`) manages visual quality inspection across 3 machining and assembly shifts:
- Inspectors visually audit steel fasteners (`metal_nut`, `screw`), structural surfaces (`grid`, `tile`), and raw cold-rolled steel coils (`steel_sheet`).
- Current manual inspection suffers from an **escape rate of ~1.8%** (defective components shipped to downstream automotive OEM customers).
- In automotive supply contracts, customer complaints and line-stoppage warranty penalties cost **50× more** than the scrap cost of a false reject.
- Whenever suppliers switch steel smelting batches or machine tooling wears down, **novel, previously unseen defect topologies emerge** (e.g., internal metallurgical voids, novel scratch textures, oxidation streaks). Pure supervised classifiers miss these novel defects completely because they were never in the training set.

**Core Requirements**:
1. **Unsupervised Anomaly Detection (M1)**: Train on normal/good components only (MVTec AD categories `metal_nut`, `screw`, `grid`, `tile`). Image AUROC $\ge 0.95$ and local CPU inference latency $< 100$ ms with 2D anomaly heatmap localization.
2. **Calibrated Defect Classification (M2)**: Supervised 7-class defect classifier on known steel defects (NEU surface dataset: `crazing`, `inclusion`, `patches`, `pitted_surface`, `rolled_in_scale`, `scratches`, plus `good`) with temperature-scaling calibration ($T$) to ensure posterior probabilities represent true empirical risk.
3. **Cost-Optimal Operating Point (M3)**: Deterministic decision engine using asymmetric cost matrices ($C_{\text{escape}} = 50$, $C_{\text{false\_reject}} = 1$, $C_{\text{review}} = 0.3$) routing parts to `PASS`, `REVIEW`, or `REJECT` instead of naive F1 thresholds.
4. **Real-Time Edge Inspection Service (M4)**: Ingestion watcher with ORB reference alignment, MinIO heatmap storage, PostgreSQL audit ledger, and sub-150ms P95 latency.
5. **Continuous Retraining & Shadow Promotion (M5)**: Review queue labeling, versioned dataset manifests (content hashes), candidate training, shadow execution, and drift monitoring (Population Stability Index $> 0.2$ alerting).
6. **Web Console UI (M6)**: Operator inspection station at `/inspection` with live wall, heatmap opacity slider, review queue keyboard shortcuts, and model promotion controls.

## 2. Architecture & Hybrid Inspection Pipeline

```mermaid
graph TD
    subgraph Ingest ["1. Ingestion & Alignment"]
        LineCam["Line Camera / Folder Watcher"] --> IngestAPI["POST /inspect"]
        IngestAPI --> Preprocess["Preprocess: Fixed ROI Crop (256x256)"]
        Preprocess --> Align["ORB Reference Keypoint Alignment"]
    end

    subgraph Dual_Inference ["2. Dual-Engine Feature Inference"]
        Align --> AnomalyEngine["PatchCore Anomaly Detector (Unsupervised, Good-Only)"]
        Align --> ClassEngine["ResNet-18 Defect Classifier (Supervised, 7-Class Calibrated)"]
        AnomalyEngine --> AnomScore["Anomaly Score s ∈ [0, 1] + Heatmap"]
        ClassEngine --> ClassProb["Calibrated Probabilities P(c|x)"]
    end

    subgraph Decision ["3. Cost-Based Decision Engine"]
        AnomScore & ClassProb --> CostEngine["Cost Matrix Evaluator (C_escape=50, C_reject=1)"]
        CostEngine --> OperatingPoint{"Decision Gates"}
        OperatingPoint -->|s < t_pass & P(good) ≥ 0.95| Pass["PASS (92% Auto-Accept)"]
        OperatingPoint -->|t_pass ≤ s < t_reject| Review["REVIEW QUEUE (≤8% Operator Audit)"]
        OperatingPoint -->|s ≥ t_reject or P(defect) ≥ 0.90| Reject["REJECT (Immediate Quarantined Scrap)"]
        Pass -.->|2% Seeded Random Audit| Review
    end

    subgraph Retrain_Loop ["4. Closed Retraining & Shadow Loop"]
        Review --> HumanReview["Mehmet / Quality Operator Review UI"]
        HumanReview --> LabelManifest["Versioned Dataset Manifest (Content Hashes)"]
        LabelManifest --> RetrainJob["Automated Retrain Job (Candidate Model)"]
        RetrainJob --> Shadow["Shadow Mode Deployment (No Live Decision Impact)"]
        Shadow --> GateCheck{"Gate: Escape Rate Drop & Zero Per-Class Drop"}
        GateCheck -->|Pass| Promote["Promote to Production (MLflow Registry)"]
        GateCheck -->|Fail| Rollback["Instant Rollback"]
    end
```

## 3. Milestones & Delivery Schedule

- [x] **M1: Anomaly Baselines with MVTec AD**:
  - Unsupervised PatchCore memory-bank coreset anomaly engine trained on normal/good samples only across `metal_nut`, `screw`, `grid`, and `tile`.
  - Greedy $k$-Center coreset subsampling ($10\%$ ratio) reducing memory and latency for local CPU execution.
  - 2D Gaussian-smoothed pixel anomaly heatmap generation and normalized image anomaly score ($0.0 - 1.0$).
  - Preprocessing pipeline with fixed ROI cropping, bicubic resize (256×256), normalization, and ORB keypoint reference alignment.
  - Benchmark report generated at `evals/reports/p6/anomaly_baselines.md` (Image AUROC $\ge 0.95$, latency $< 100$ ms).
- [x] **M2: Supervised Defect Classifier (NEU Steel Surface)**:
  - 7-class taxonomy: `[crazing, inclusion, patches, pitted_surface, rolled_in_scale, scratches, good]`.
  - Kaggle fine-tuning notebook `notebooks/kaggle/p6_cls.ipynb` with ResNet-18, label smoothing 0.1, stratified 70/15/15 splits, and dHash cross-split deduplication.
  - Temperature scaling calibration ($T$) on validation split guaranteeing calibrated posterior probabilities.
  - Production runtime classifier `services/vision-edge/fieldkit_vision/inspect/classifier.py` executing via ONNX Runtime.
  - Product inspection configurations in `configs/inspection/*.yaml`.
- [x] **M3: Decision Engine with Cost-Based Thresholds**:
  - Asymmetric cost matrix optimization minimizing expected cost subject to review budget $\le 8\%$.
  - Pure deterministic decision state machine (`fieldkit_vision/inspect/decision.py`) routing parts to `PASS`, `REJECT`, or `REVIEW`.
  - Cryptographically seeded 2% random audit sampling on clean `PASS` items to monitor drift without operator fatigue.
  - End-to-end evaluation benchmark report in `evals/reports/p6/decision_engine.md` achieving 0.0% defect escape rate, 7.0% review queue rate, and 57.1x cost reduction vs naive cutoff.
- [ ] **M4: Inspection Service + Heatmaps**:
  - Live inspection worker, MinIO heatmap overlay storage, PostgreSQL schema, Prometheus metrics, and locust load testing.
- [ ] **M5: Review, Labeling, Retraining, Shadow & Promotion**:
  - Review API, versioned dataset manifests (`manifest.py`), candidate training, shadow execution, and PSI drift monitoring.
- [ ] **M6: Inspection Console UI (`/inspection`)**:
  - Next.js 14 console section with live inspection grid, heatmap overlay slider, review queue keyboard shortcuts, and model promotion controls.
