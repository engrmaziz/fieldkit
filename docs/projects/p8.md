**Status**: Complete — Milestones 0 through 6 Delivered (Production Ready)  
**Customer Persona**: Tobias Becker (Plant IT & Infrastructure Administrator, Halden Industrie GmbH)  
**Target Environment**: Air-gapped Operational Technology (OT) Plant Network (`DE-HAM-OT`), zero outbound Internet access, USB/local bundle installation.

## 1. Executive Summary & Customer Story

Halden Industrie's manufacturing facilities operate under strict IEC 62443 industrial cybersecurity policies: production subnets are air-gapped with zero outbound Internet access. Previous vendor software failed because it required persistent cloud connections, public container registries, or SaaS control planes.

Tobias Becker requires:
1. **Single-Bundle Offline Installation**: Fieldkit must install completely from an offline USB drive / local archive (`fieldkit-<version>-airgap.tar.zst`) in under 20 minutes with zero network egress.
2. **Durable, Crash-Proof Orchestration**: Recurring business processes across Projects 1–7 (nightly data ingestion, entity resolution, automated model retraining, shadow inference, and backup procedures) must run under an event-sourced workflow engine in **Go 1.23+**. If the server reboots or the engine process is killed mid-workflow, execution resumes from the append-only event log without duplicate side-effects.
3. **Deterministic Human Governance**: Risky actions (such as promoting defect inspection models or executing ERP database mutations) must pause at an explicit approval gate and wait for operator sign-off before proceeding.
4. **Disaster Recovery & Zero-Downtime Rollbacks**: Point-in-time PostgreSQL custom backups, MinIO object snapshots, and automated rollback if upgrades fail health gates.

## 3. Database Schema & Event Sourcing

The engine state is 100% reconstructed via event log replay, eliminating out-of-sync in-memory state:

### 3.1 `workflow_def`
- `name` (TEXT, PK)
- `version` (TEXT, PK)
- `yaml_content` (TEXT, NOT NULL)
- `content_hash` (TEXT, NOT NULL)
- `created_at` (TIMESTAMP WITH TIME ZONE, NOT NULL)

### 3.2 `workflow_run`
- `id` (UUID, PK)
- `def_name` (TEXT, NOT NULL)
- `def_version` (TEXT, NOT NULL)
- `status` (TEXT, NOT NULL: `PENDING`, `RUNNING`, `SUSPENDED`, `COMPLETED`, `FAILED`, `CANCELLED`)
- `input_json` (JSONB, NOT NULL)
- `output_json` (JSONB)
- `error_text` (TEXT)
- `created_at` (TIMESTAMP WITH TIME ZONE, NOT NULL)
- `updated_at` (TIMESTAMP WITH TIME ZONE, NOT NULL)

### 3.3 `workflow_event`
- `run_id` (UUID, NOT NULL)
- `seq` (INT, NOT NULL)
- `event_type` (TEXT, NOT NULL: `WorkflowStarted`, `StepScheduled`, `StepStarted`, `StepCompleted`, `StepFailed`, `TimerFired`, `SignalReceived`, `ApprovalGranted`, `CompensationStarted`, `WorkflowCompleted`, `WorkflowFailed`)
- `payload_json` (JSONB, NOT NULL)
- `created_at` (TIMESTAMP WITH TIME ZONE, NOT NULL)
- `PRIMARY KEY (run_id, seq)`

### 3.4 `workflow_task`
- `id` (UUID, PK)
- `run_id` (UUID, NOT NULL)
- `step_id` (TEXT, NOT NULL)
- `attempt` (INT, NOT NULL DEFAULT 1)
- `status` (TEXT, NOT NULL: `QUEUED`, `LEASED`, `COMPLETED`, `FAILED`)
- `lease_owner` (TEXT)
- `lease_until` (TIMESTAMP WITH TIME ZONE)
- `run_after` (TIMESTAMP WITH TIME ZONE NOT NULL)
- `idempotency_key` (TEXT UNIQUE NOT NULL)

## 4. Shipped Production Workflows (`workflows/`)

1. **`nightly-ingest.yaml`**: Triggers P1 ingest workers across ERP, SOAP, and Excel $\to$ calculates schema drift fingerprints $\to$ executes Splink + LLM entity resolution $\to$ promotes canonical staging records to production.
2. **`retrain-promote.yaml`**: Monitors material drift $\to$ triggers PatchCore retraining on MVTec AD / NEU dataset $\to$ runs frozen test set evaluation gate $\to$ launches shadow inference mode $\to$ suspends for **Quality Lead Human Approval** (`human_approval`) $\to$ executes zero-downtime model promotion.
3. **`weekly-insights.yaml`**: Pulls incident tickets from P3 Ops Copilot $\to$ calculates multi-plant scrap trends $\to$ dispatches email executive briefing via Mailpit SMTP.
4. **`nightly-evals.yaml`**: Runs P2 RAG/NL2SQL and P7 Observability regression suites $\to$ checks metric baselines $\to$ alerts on drift.
5. **`daily-backup.yaml`**: Triggers automated PostgreSQL binary dump + MinIO bucket mirroring with retention enforcement.
