# Fieldkit MLOps Package

MLOps primitives for Project 6 Industrial Defect Inspection:
- Dataset manifests with SHA-256 and 64-bit dHash cross-split deduplication
- Unsupervised anomaly training & coreset subsampling
- Supervised defect classifier training with temperature calibration
- Model evaluation metrics (Image AUROC, Pixel AUROC, PRO, ECE, Confusion Matrix)
- Local Model Registry with candidate, production, and rollback lifecycle
